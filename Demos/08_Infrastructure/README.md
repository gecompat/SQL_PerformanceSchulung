# Infrastruktur-Demos

## Zweck

T-SQL-Begleitskripte und Beobachtung für RAM-, CPU-, I/O-, Netzwerk-, Mehrinstanz- und Failover-Labs.

Dieser Platzhalter enthält keine ausführbaren Skripte. Der vorhandene Einstieg beginnt bei der [lokalen Testumgebung](../../Documentation/HowTo/LOCAL_TEST_ENVIRONMENT.md) beziehungsweise beim [Docker-/Podman-Quickstart](../../Documentation/HowTo/CONTAINER_QUICKSTART.md). Der [Demo-Katalog](../../Documentation/Demo_Catalog/README.md) benennt je Demo den erforderlichen Ausführungspfad; daraus folgt kein allgemeines Provisionierungsversprechen für die hier aufgeführten Sonderlabore.
