# Laufzeitartefakte

Dieses Verzeichnis nimmt flüchtige Diagnose-, Export- und Testartefakte auf, die während lokaler Läufe erzeugt werden. Beispiele sind normalisierte Diagnosepakete, temporäre Berichte oder lokal erzeugte Nachweise.

Der gesamte Laufzeitinhalt ist von Git ausgeschlossen. Dauerhafte, fachlich relevante Ergebnisse müssen nach Prüfung in ein dafür vorgesehenes Dokumentations- oder Vertragsartefakt überführt werden. Rohdaten, Secrets und produktive Diagnosedaten sind nicht zulässig.
