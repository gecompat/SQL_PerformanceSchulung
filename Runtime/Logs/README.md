# Laufzeitprotokolle

Dieses Verzeichnis ist für lokale Protokolle von Szenario-, Runner-, Test- und Hilfsprozessen vorgesehen.

Protokolle sind flüchtig und werden vollständig von Git ausgeschlossen. Sie dürfen keine Kennwörter, Verbindungszeichenfolgen, reale Endpunkte oder produktive SQL-Texte enthalten. Dauerhafte technische Erkenntnisse sind in neutralisierter Form in die Projektdokumentation zu überführen.
