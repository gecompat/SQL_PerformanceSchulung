# Temporäre Laufzeitdateien

Dieses Verzeichnis enthält ausschließlich kurzlebige Zwischenprodukte lokaler Szenario-, Test- und Werkzeugausführungen.

Inhalte müssen jederzeit ohne fachlichen Informationsverlust gelöscht werden können. Werkzeuge sollen bevorzugt das betriebssystemseitige Temp-Verzeichnis verwenden. Dieses Verzeichnis ist nur dann zu verwenden, wenn ein Zwischenprodukt bewusst innerhalb des Repositoryarbeitsbaums benötigt wird.
