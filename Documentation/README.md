# Documentation

Dieser Bereich enthält die lehrgangsweite fachliche Dokumentation.

| Ordner | Inhalt |
|---|---|
| `Project_Planning/` | Master-Umsetzungsplan, quellenbasierte Vertiefungspläne, Masterdeck-Variantenarchitektur, Arbeitspakete, Abhängigkeiten, Gates und Wiederaufnahmeverfahren |
| `Curriculum/` | Lernpfade, Zielgruppen, Voraussetzungen und Reihenfolge |
| `Demo_Catalog/` | Zuordnung von Themen, Folien, Demos, Versionen und Sicherheitsstufen |
| `Research/` | Quellenbasierte Fachprüfung und dokumentierte Recherche |

Der verbindliche Gesamtplan liegt in [`Project_Planning/MASTER_IMPLEMENTATION_PLAN.md`](Project_Planning/MASTER_IMPLEMENTATION_PLAN.md).

Der modulübergreifende Plan für vertiefende Query-Processing-, Execution-Plan-, Parameter-Sensitivity-, Memory-, IQP- und Incident-LABs liegt in [`Project_Planning/ADVANCED_PERFORMANCE_BLOCK_PLAN.md`](Project_Planning/ADVANCED_PERFORMANCE_BLOCK_PLAN.md). Er ergänzt den Gesamtplan und ändert dessen Kernpfad nicht.

Die Ableitung der Tiefenprofile `BASIS`, `STANDARD` und `VERTIEFUNG` aus dem kanonischen PowerPoint-Masterdeck wird in [`Project_Planning/MASTER_DECK_VARIANT_ARCHITECTURE.md`](Project_Planning/MASTER_DECK_VARIANT_ARCHITECTURE.md) geregelt.

Objektspezifische Bedienungs- und Interpretationshinweise verbleiben bei der jeweiligen Demo. Übergreifende Erklärungen werden hier zentral geführt und nicht unkontrolliert dupliziert.
